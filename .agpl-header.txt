USAGE
-----
Add the appropriate header block below to EVERY new source file you create.
This satisfies the AGPL-3.0 requirement that modified source files carry
prominent notices of modification.

For PHP files — immediately after <?php:

    <?php
    // Copyright (C) 2026 Anubisland
    // Built on Project NEXUS by Jasper Ford — https://github.com/jasperfordesq-ai/nexus-v1
    // SPDX-License-Identifier: AGPL-3.0-or-later
    // This file is part of the Hyper-Local Community Platform.
    // See CHANGES.md for a record of modifications from the upstream source.

For TypeScript / TSX files — at the top of the file:

    // Copyright (C) 2026 Anubisland
    // Built on Project NEXUS by Jasper Ford — https://github.com/jasperfordesq-ai/nexus-v1
    // SPDX-License-Identifier: AGPL-3.0-or-later
    // This file is part of the Hyper-Local Community Platform.
    // See CHANGES.md for a record of modifications from the upstream source.

For JavaScript files:

    // Copyright (C) 2026 Anubisland
    // Built on Project NEXUS by Jasper Ford — https://github.com/jasperfordesq-ai/nexus-v1
    // SPDX-License-Identifier: AGPL-3.0-or-later
    // This file is part of the Hyper-Local Community Platform.
    // See CHANGES.md for a record of modifications from the upstream source.

TOOLING
-------
The CONTRIBUTING.md SPDX Header Requirement section describes automated
tooling for adding and verifying headers:

    # Add headers to all files missing them
    node scripts/add-spdx-headers.mjs

    # Verify all files have correct headers
    node scripts/check-spdx.mjs
